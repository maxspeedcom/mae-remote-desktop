# MAE Remote Desktop

MAE Remote Desktop is a modified version of an open-source remote desktop program, version 1.5.0,
distributed under the same license (GNU AGPL-3.0, see `LICENCE`).

## Changes from the upstream 1.5.0 source

- App name `MAERemote`, organisation `com.maesuaisystem`.
- Default rendezvous/relay server `rd.maesuaisystem.com` with its public key.
- Account API points to https://remote.maesuaisystem.com (our own account service) instead of the upstream project's server.
- Windows file metadata (product name, description, copyright).
- Brand colour `#4C3BFF`, new app icon and logo.
- Download, website and privacy links point to https://remote.maesuaisystem.com.
- Window title shows "MAE Remote"; the About page shows MAE Remote Desktop and keeps the original copyright notice (Purslane Tech Pte. Ltd., GNU AGPL-3.0) with a link to this source. The "Powered by" label is hidden.
- `libs/hbb_common` is vendored (was a git submodule) so the changes above build in CI.
- `.github/workflows/mae-windows.yml`: Windows x64 build only, generated by `gen-workflow.py`.
- Upstream push/schedule workflows removed; only `mae-windows.yml` and the reusable build workflows it calls remain.

All changes are applied by `apply-branding.py`; source for every released build is published in this repository.
- Default image quality is "Good image quality" (`best`) instead of Balanced; users can still change it per session or in Settings → Display.
- The main window title bar shows "MAE Remote Desktop" next to the logo (upstream shows the logo only). Window titles, the taskbar, the tray tooltip and UI text show "MAE Remote" (with a space); the runner and `core_main.rs` look the main window up by that same title, so single-instance detection still works. `APP_NAME` stays `MAERemote` (service, install folder, exe name).
- Windows file metadata of the main exe and DLL (InternalName/OriginalFilename `MAERemote`), and `README.md` replaced with the MAE Remote Desktop readme.
- Update notice: at start-up the app reads https://remote.maesuaisystem.com/version.json and, when its `build` is newer than `MAE_BUILD`, shows a "new version" card that opens the download page. The upstream auto-updater (which downloads upstream installers) is disabled.
- Traffic report (build 8): the computer being controlled counts the bytes each session sends and receives (`CountedStream` in `src/server/connection.rs`, file blocks via `handle_read_jobs_counted` in `libs/base/src/fs.rs`) and posts the running totals to the account API (`/api/audit/conn`, action `traffic`) at most every 5 s, plus the final totals in the `close` record. Only byte counts and connection IDs are sent, never content. The service monitor uses them for live and history traffic charts, including direct sessions that never pass through the server.
- The remote screen fits the window by default (view style "Scale adaptive" instead of "Scale original", which needed scroll bars when the remote screen is larger than the window). At the first start of build 8, computers saved with the old default are switched once; a choice made afterwards in the toolbar (Display) is kept.
- Build 9: the program inside the installer is `MAERemote.exe` (the name the installed shortcuts, the service and the registry use; earlier builds shipped it under the upstream file name, so after installing, the desktop icon and the service could not start it), and the installer renames the copied program the same way the updater does.
